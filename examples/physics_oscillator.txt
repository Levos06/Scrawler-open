# Лекция 7. Гармонический осциллятор
Осциллятор - самая важная модель в физике: почти любая система вблизи устойчивого равновесия колеблется гармонически.

# 1. Пружинный маятник
Груз массы $m$ на пружине жёсткости $k$. Сила Гука:
$F = -kx$
Второй закон Ньютона даёт уравнение движения:
$m\ddot{x} = -kx$
Обозначим $\omega_0^2 = k/m$, тогда
$\ddot{x} + \omega_0^2 x = 0$
Общее решение - гармоническое колебание:
$x(t) = A\cos(\omega_0 t + \varphi)$
Здесь $A$ - амплитуда, $\varphi$ - начальная фаза. Они находятся из начальных условий $x(0)=x_0$ и $\dot{x}(0)=v_0$:
$A = \sqrt{x_0^2 + v_0^2/\omega_0^2}$
$\tan\varphi = -\frac{v_0}{\omega_0 x_0}$
Период и частота не зависят от амплитуды:
$T = \frac{2\pi}{\omega_0} = 2\pi\sqrt{\frac{m}{k}}$
Это свойство называется изохронностью.

# 2. Энергия колебаний
Кинетическая и потенциальная энергия:
$K = \frac{m\dot{x}^2}{2}, \quad U = \frac{kx^2}{2}$
Подставим решение $x(t)$:
$K = \frac{kA^2}{2}\sin^2(\omega_0 t + \varphi)$
$U = \frac{kA^2}{2}\cos^2(\omega_0 t + \varphi)$
Сумма постоянна:
$E = K + U = \frac{kA^2}{2} = \frac{m\omega_0^2 A^2}{2}$
Средние за период равны друг другу:
$\langle K \rangle = \langle U \rangle = \frac{E}{2}$
Энергия перекачивается из кинетической в потенциальную и обратно дважды за период.

# 3. Математический маятник
Точечная масса на нити длины $l$. Уравнение для угла:
$ml\ddot{\theta} = -mg\sin\theta$
При малых углах $\sin\theta \approx \theta$, и
$\ddot{\theta} + \frac{g}{l}\theta = 0$
$\omega_0 = \sqrt{g/l}, \quad T = 2\pi\sqrt{l/g}$
Для конечной амплитуды $\theta_0$ период растёт:
$T \approx 2\pi\sqrt{\frac{l}{g}}\left(1 + \frac{\theta_0^2}{16}\right)$
Изохронность нарушается - колебания становятся ангармоническими.

# 4. Фазовая плоскость
Состояние осциллятора задаётся парой $(x, p)$, где $p = m\dot{x}$.
Из закона сохранения энергии:
$\frac{p^2}{2m} + \frac{m\omega_0^2 x^2}{2} = E$
Фазовая траектория - эллипс с полуосями
$a = \sqrt{\frac{2E}{m\omega_0^2}}, \quad b = \sqrt{2mE}$
Площадь эллипса:
$S = \pi a b = \frac{2\pi E}{\omega_0}$
Отношение $E/\omega_0$ - адиабатический инвариант: оно сохраняется при медленном изменении параметров.

# 5. Затухающие колебания
Добавим силу вязкого трения $F = -b\dot{x}$:
$\ddot{x} + 2\gamma\dot{x} + \omega_0^2 x = 0, \quad \gamma = \frac{b}{2m}$
Ищем решение в виде $x = e^{\lambda t}$:
$\lambda^2 + 2\gamma\lambda + \omega_0^2 = 0$
$\lambda = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}$
При слабом затухании $\gamma < \omega_0$:
$x(t) = A e^{-\gamma t}\cos(\omega t + \varphi)$
$\omega = \sqrt{\omega_0^2 - \gamma^2}$
Амплитуда спадает экспоненциально, время жизни $\tau = 1/\gamma$.
Логарифмический декремент затухания:
$\delta = \ln\frac{x(t)}{x(t+T)} = \gamma T$
Добротность - число колебаний за время затухания, умноженное на $\pi$:
$Q = \frac{\omega_0}{2\gamma}$
При $\gamma = \omega_0$ - критическое затухание, система возвращается быстрее всего и без колебаний.
При $\gamma > \omega_0$ - апериодический режим.

# 6. Вынужденные колебания
Внешняя сила $F_0\cos\Omega t$:
$\ddot{x} + 2\gamma\dot{x} + \omega_0^2 x = \frac{F_0}{m}\cos\Omega t$
После затухания переходного процесса остаётся установившееся решение:
$x(t) = a(\Omega)\cos(\Omega t - \psi)$
Амплитуда и сдвиг фазы:
$a(\Omega) = \frac{F_0/m}{\sqrt{(\omega_0^2 - \Omega^2)^2 + 4\gamma^2\Omega^2}}$
$\tan\psi = \frac{2\gamma\Omega}{\omega_0^2 - \Omega^2}$
Резонанс - максимум амплитуды при
$\Omega_r = \sqrt{\omega_0^2 - 2\gamma^2}$
При малом затухании ширина резонансной кривой на половине мощности:
$\Delta\Omega \approx 2\gamma = \frac{\omega_0}{Q}$
Чем выше добротность, тем острее резонанс.
Средняя поглощаемая мощность:
$\langle P \rangle = \frac{F_0^2}{m}\frac{\gamma\Omega^2}{(\omega_0^2 - \Omega^2)^2 + 4\gamma^2\Omega^2}$

# 7. Комплексная запись
Удобно писать $x = \mathrm{Re}\, z$, где $z$ удовлетворяет
$\ddot{z} + 2\gamma\dot{z} + \omega_0^2 z = \frac{F_0}{m}e^{i\Omega t}$
Подстановка $z = z_0 e^{i\Omega t}$ сразу даёт
$z_0 = \frac{F_0/m}{\omega_0^2 - \Omega^2 + 2i\gamma\Omega}$
Модуль $z_0$ - амплитуда, аргумент - фаза. Так считать проще, чем через тригонометрию.

# 8. Связанные осцилляторы
Два одинаковых маятника, соединённые пружиной жёсткости $\kappa$:
$m\ddot{x}_1 = -kx_1 - \kappa(x_1 - x_2)$
$m\ddot{x}_2 = -kx_2 - \kappa(x_2 - x_1)$
Нормальные координаты:
$q_1 = x_1 + x_2, \quad q_2 = x_1 - x_2$
Они колеблются независимо с частотами
$\omega_1 = \sqrt{k/m}, \quad \omega_2 = \sqrt{(k + 2\kappa)/m}$
Если сначала качнуть только первый маятник, энергия переходит ко второму и обратно - биения с частотой
$\Omega_b = \omega_2 - \omega_1$
В общем случае $N$ степеней свободы: ищем $x = a e^{i\omega t}$ и решаем
$\det(K - \omega^2 M) = 0$

# 9. Квантовый осциллятор
Гамильтониан:
$\hat{H} = \frac{\hat{p}^2}{2m} + \frac{m\omega^2\hat{x}^2}{2}$
Уравнение Шрёдингера для стационарных состояний:
$-\frac{\hbar^2}{2m}\psi'' + \frac{m\omega^2 x^2}{2}\psi = E\psi$
Уровни энергии эквидистантны:
$E_n = \hbar\omega\left(n + \frac{1}{2}\right), \quad n = 0, 1, 2, \ldots$
Энергия нулевых колебаний $E_0 = \hbar\omega/2$ не равна нулю - это следствие соотношения неопределённостей:
$\Delta x \, \Delta p \geq \frac{\hbar}{2}$
Основное состояние - гауссиана:
$\psi_0(x) = \left(\frac{m\omega}{\pi\hbar}\right)^{1/4} e^{-m\omega x^2/2\hbar}$

# 10. Лестничные операторы
Введём
$\hat{a} = \sqrt{\frac{m\omega}{2\hbar}}\left(\hat{x} + \frac{i\hat{p}}{m\omega}\right)$
и сопряжённый к нему $\hat{a}^\dagger$. Коммутатор:
$[\hat{a}, \hat{a}^\dagger] = 1$
Гамильтониан принимает вид
$\hat{H} = \hbar\omega\left(\hat{a}^\dagger\hat{a} + \frac{1}{2}\right)$
Операторы повышают и понижают номер уровня:
$\hat{a}^\dagger|n\rangle = \sqrt{n+1}\,|n+1\rangle$
$\hat{a}|n\rangle = \sqrt{n}\,|n-1\rangle$
Все состояния получаются из основного:
$|n\rangle = \frac{(\hat{a}^\dagger)^n}{\sqrt{n!}}|0\rangle$
Среднее значение координаты в стационарном состоянии равно нулю, а дисперсия растёт с номером:
$\langle x^2 \rangle_n = \frac{\hbar}{m\omega}\left(n + \frac{1}{2}\right)$

# 11. Итоги
Гармонический осциллятор описывает колебания молекул, фононы в кристалле, моды электромагнитного поля в резонаторе.
Главное запомнить:
$\omega_0 = \sqrt{k/m}, \quad E = \frac{m\omega_0^2 A^2}{2}, \quad Q = \frac{\omega_0}{2\gamma}$
$E_n = \hbar\omega\left(n + \frac{1}{2}\right)$
Классический и квантовый осцилляторы имеют одну и ту же частоту, но квантовый не может покоиться.
